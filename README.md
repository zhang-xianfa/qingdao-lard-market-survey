## 一、研究背景

青岛脂渣是山东省级非物质文化遗产代表性项目，以猪五花肉熬炼而成，是青岛及胶东地区
的传统地方食品。研究关注三个现实问题：年轻消费群体对脂渣这类高油传统食品的接受度如何、
非遗文化属性对购买意愿的贡献有多大、以及面向不同人群该采取怎样的营销策略。

研究对象分为**高校学生群体**与**城市居民群体**两类，分别采集问卷，以便对比两类人群在
健康顾虑、文化认同与价格敏感度上的差异。

### 2.1 结构方程模型（SOR 框架）

采用 SOR（Stimulus–Organism–Response）理论建立消费机制模型：外部**营销刺激**作用于
消费者的**感知价值**，进而影响**消费意愿**，并以**健康意识**作为抑制因素。

潜变量设定：

| 潜变量 | 观测维度 |
|---|---|
| 消费意愿 A | 未来购买意愿、推荐意愿、比较购买意愿 |
| 健康意识 B | 管控油炸食品摄入、健康选择偏好、健康状况认知、尝新倾向 |
| 感知价值（高阶） | 由价格价值 C、情感价值 D、体验价值 F、社会价值 G、文化价值 H 五个子维度整合 |
| 营销刺激 I | 限量营销、特价促销、IP 联名、文化特色包装、高分评价、线上活动、线下活动 |

研究假设 H1–H8 与模型修正过程见 [`docs/研究设计.md`](docs/研究设计.md)。
