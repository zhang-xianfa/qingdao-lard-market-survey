# 研究设计

## 一、题目

「脂香盈岸忆青岛，非遗焕彩引青衿」—— 青岛脂渣的消费机制与营销策略赋能研究

## 二、研究框架

以 SOR（Stimulus–Organism–Response）理论为主框架：

```
营销刺激 I  ──H3──►  消费意愿 A
     │                    ▲
   H4│                    │ H2
     ▼                    │
  感知价值  ──────────────┘
 （高阶潜变量）
     ▲            ▲
   H5│            │ H2a~H2e
     │            │
  健康意识 B   价格C / 情感D / 体验F / 社会G / 文化H
```

## 三、潜变量与观测变量

| 潜变量 | 可测变量 |
|---|---|
| 消费意愿 A | 未来购买意愿 a1、推荐意愿 a2、比较购买意愿 a3 |
| 健康意识 B | 对油炸食品摄入的控制 b1、对自身健康状况的认知 b2、健康饮食选择偏好 b3、尝试新的食物 b4 |
| 感知价格价值 C | 能接受青岛脂渣的最高价格范围 c1、物有所值价格合理 c2、即使价格较高也愿意买单 c3 |
| 感知情感价值 D | 缓解压力心情变好 d1、减轻负面情绪 d2、温暖亲切的感觉 d3 |
| 感知体验价值 F | 地域饮食文化新奇 f1、制作工艺新奇 f2、探索体验青岛非遗文化 f3 |
| 感知社会价值 G | 作为特产礼物送他人 g1、社交认同感 g2、社交场合中受欢迎的话题 g3 |
| 感知文化价值 H | 青岛独特饮食文化传统 h1、文化认同感 h2、非遗文化魅力 h3 |
| 营销刺激 I | 限量营销 i1、特价促销 i2、IP 联名 i3、文化特色包装 i4、高分评价 i5、电商平台优惠券 / 直播带货 / 新人优惠等线上活动 i6、线下品鉴 / 美食街活动 i7 |

对应问卷题目：消费意愿为第 13 题，健康意识为第 14 题，感知价值为第 18 题，营销刺激为第 23 题。

## 四、研究假设

| 编号 | 假设 |
|---|---|
| H1 | 健康意识对消费意愿有显著**负向**影响 |
| H2 | 感知价值对消费意愿有显著**正向**影响 |
| H2a | 感知价格价值正向影响感知价值 |
| H2b | 感知情感价值正向影响感知价值 |
| H2c | 感知体验价值正向影响感知价值 |
| H2d | 感知社会价值正向影响感知价值 |
| H2e | 感知文化价值正向影响感知价值 |
| H3 | 营销刺激对消费意愿有显著**正向**影响 |
| H4 | 营销刺激对感知价值有显著**正向**影响 |
| H5 | 健康意识对感知价值有显著**负向**影响 |
| H6 | 感知价值在营销刺激与消费意愿之间存在**中介作用** |
| H7 | 感知价值内部各潜变量间有显著相关关系 |
| H8 | 消费者特征（性别、年龄、地域、消费能力）对 H1–H6 的路径关系具有**调节作用** |

## 五、模型修正记录

初始模型拟合后出现路径不显著、部分关系无法得出确定值的情况，判断为结构方程模型设计缺陷
（理论上可行但数据上不可执行）。调整方案：删除 H1、H7 的部分路径及部分不显著的可测变量路径，
重新估计得到修正模型。

## 八、随机森林特征重要性

以购买频率为因变量，7 个感知价值潜在变量为自变量：

| 变量 | 含义 |
|---|---|
| X1 | 感知价格价值 |
| X2 | 感知情感价值 |
| X3 | 感知体验价值 |
| X4 | 感知社会价值 |
| X5 | 感知文化价值 |
| X6 | 健康意识 |
| X7 | 营销感知 |

评价标准为基尼指数减少量（Gini gain），按特征重要性降序排列。
全体样本的重要性得分：价格价值 0.178 > 营销感知 0.163 > 健康意识 0.159 >
社会价值 0.147 > 情感价值 0.123 > 文化与体验价值 0.115。
